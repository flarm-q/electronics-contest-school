# K230D 视觉巡线调参与串口说明

## 1. 当前视觉巡线控制位置

K230D 视觉巡线接入 STM32 后，主要控制参数位于：

```text
HARDWARE/CONTROL/control.c
```

当前视觉巡线不复用旧八路传感器巡线状态表，而是使用 K230D 发送的连续视觉误差：

```text
$L,error,angle,confidence,flags#
```

STM32 收到后，根据 `error` 和 `angle` 计算转向输出。

## 2. 视觉巡线相关参数

在 `HARDWARE/CONTROL/control.c` 中查找以下参数：

```c
#define K230_LINE_BASE_SPEED -10
#define K230_LINE_MIN_CONFIDENCE 35
#define K230_LINE_TURN_LIMIT 100
#define K230_LINE_ERROR_KP 0.32f
#define K230_LINE_ANGLE_KD 0.18f
```

### 2.1 K230_LINE_BASE_SPEED

```c
#define K230_LINE_BASE_SPEED -10
```

作用：视觉巡线时的基础前进速度。

说明：

- 当前工程里负值表示当前接线和编码器方向下的前进方向。
- 如果车速太慢，可以适当增大绝对值，例如 `-12`、`-15`。
- 如果车容易冲出弯道，先减小绝对值，例如 `-8`、`-6`。

调试建议：

```text
先低速跑通巡线，再逐步提高速度。
```

### 2.2 K230_LINE_MIN_CONFIDENCE

```c
#define K230_LINE_MIN_CONFIDENCE 35
```

作用：视觉识别可信度阈值。

说明：

- K230D 识别到黑线后会给出 `confidence`。
- STM32 只有在 `confidence >= K230_LINE_MIN_CONFIDENCE` 时才允许视觉巡线接管。
- 这个值太低，容易把内圆、短横线、阴影误当成主线。
- 这个值太高，可能导致正常黑线也不接管。

调试建议：

```text
如果车经常不动或不进入巡线，适当降低。
如果车被内圆或噪声干扰，适当提高。
```

### 2.3 K230_LINE_TURN_LIMIT

```c
#define K230_LINE_TURN_LIMIT 100
```

作用：限制视觉转向输出最大值。

说明：

- 防止视觉误差突变时转向过猛。
- 值越大，允许转向越激烈。
- 值越小，转向更柔和，但急弯可能转不过来。

调试建议：

```text
如果车左右猛摆，降低该值。
如果弯道转不过去，适当提高该值。
```

### 2.4 K230_LINE_ERROR_KP

```c
#define K230_LINE_ERROR_KP 0.32f
```

作用：视觉横向偏差比例项。

对应关系：

```text
turn += error * K230_LINE_ERROR_KP
```

说明：

- `error` 是黑线中心相对图像中心的偏差。
- `error < 0` 表示黑线在图像左侧。
- `error > 0` 表示黑线在图像右侧。
- 这个参数类似巡线 P 项，负责当前纠偏力度。

调试建议：

```text
车偏离黑线后修正太慢：增大 K230_LINE_ERROR_KP
车左右来回摆动明显：减小 K230_LINE_ERROR_KP
```

### 2.5 K230_LINE_ANGLE_KD

```c
#define K230_LINE_ANGLE_KD 0.18f
```

作用：路线趋势项。

对应关系：

```text
turn += angle * K230_LINE_ANGLE_KD
```

说明：

- `angle` 由近处 ROI 和远处 ROI 的偏差差值得到。
- 它不是陀螺仪角速度，而是视觉前瞻趋势。
- 主要用于圆角和弯道提前转向。

调试建议：

```text
进弯太晚：增大 K230_LINE_ANGLE_KD
进弯前提前甩头或抖动：减小 K230_LINE_ANGLE_KD
```

## 3. 视觉巡线转向计算

当前 STM32 视觉巡线转向计算位于：

```text
HARDWARE/CONTROL/control.c
```

核心逻辑：

```c
turn = frame.error * K230_LINE_ERROR_KP + frame.angle * K230_LINE_ANGLE_KD;
```

然后进行限幅：

```c
if(turn > K230_LINE_TURN_LIMIT)
{
    turn = K230_LINE_TURN_LIMIT;
}
else if(turn < -K230_LINE_TURN_LIMIT)
{
    turn = -K230_LINE_TURN_LIMIT;
}
```

最终输出给左右电机差速：

```c
MOTO1 = PWM_out - Turn_out;
MOTO2 = PWM_out + Turn_out;
```

如果实车修正方向反了，优先检查 `VisionError` 方向和实际转向方向，不要盲目调大参数。

## 4. 原三环 PID 参数

原平衡车三环 PID 仍然在：

```text
HARDWARE/CONTROL/control.c
```

参数如下：

```c
float Vertical_Kp = -500;
float Vertical_Kd = -1.92f;
float Velocity_Kp = -0.44f;
float Velocity_Ki = -0.0022f;
float Turn_Kd = 0.6f;
float Turn_Kp = 20;
```

说明：

- `Vertical_Kp`、`Vertical_Kd`：直立环，决定能不能站稳。
- `Velocity_Kp`、`Velocity_Ki`：速度环，决定前后运动趋势。
- `Turn_Kp`、`Turn_Kd`：原通用转向环。

注意：

当前 K230 视觉巡线接管时，转向输出使用：

```c
Turn_out = K230_LineTurnPD();
```

因此视觉巡线转向优先调：

```text
K230_LINE_ERROR_KP
K230_LINE_ANGLE_KD
K230_LINE_TURN_LIMIT
```

不是优先调 `Turn_Kp`。

## 5. 当前串口打印内容

当前 USART1 调试串口打印位于：

```text
USER/main.c
```

打印语句：

```c
printf("Pitch=%.2f Roll=%.2f Yaw=%.2f\nVisionError=%d EncoderLeft=%d EncoderRight=%d SpeedDisplay=%.2f\r\n",
       Pitch,
       Roll,
       Yaw,
       K230_GetLineError(),
       Encoder_Left,
       Encoder_Right,
       (Encoder_Left + Encoder_Right) * 2.38f);
```

串口输出格式：

```text
Pitch=俯仰角 Roll=横滚角 Yaw=偏航角
VisionError=视觉巡线偏差 EncoderLeft=左编码器 EncoderRight=右编码器 SpeedDisplay=速度显示值
```

示例：

```text
Pitch=0.52 Roll=-1.13 Yaw=35.80
VisionError=-24 EncoderLeft=8 EncoderRight=10 SpeedDisplay=42.84
```

字段说明：

| 字段 | 含义 |
| --- | --- |
| `Pitch` | 俯仰角，平衡控制最关键 |
| `Roll` | 横滚角 |
| `Yaw` | 偏航角 |
| `VisionError` | K230D 视觉巡线偏差 |
| `EncoderLeft` | 左编码器速度 |
| `EncoderRight` | 右编码器速度 |
| `SpeedDisplay` | 编码器速度换算后的显示值 |

## 6. VisionError 判断方法

`VisionError` 来自 K230D 的 `error`：

```text
error = 黑线中心 x 坐标 - 图像中心 x 坐标
```

含义：

```text
VisionError < 0：黑线在图像左侧
VisionError > 0：黑线在图像右侧
VisionError = 0：黑线接近图像中心
```

调试时先确认：

```text
手动把黑线放到图像左侧，VisionError 应该变负。
手动把黑线放到图像右侧，VisionError 应该变正。
```

如果方向反了，应先修改视觉误差符号或转向输出符号，再调 PID。

## 7. 推荐调参顺序

### 第一步：确认视觉数据方向

观察 K230D 屏幕和 USART1 串口：

```text
黑线左移 -> VisionError 变负
黑线右移 -> VisionError 变正
```

如果方向不对，先修方向。

### 第二步：低速跑通

先保持较低速度：

```c
#define K230_LINE_BASE_SPEED -10
```

如果车太快，改小绝对值：

```c
#define K230_LINE_BASE_SPEED -6
```

### 第三步：调 K230_LINE_ERROR_KP

从小到大调：

```text
修正慢 -> 增大
左右摆 -> 减小
```

### 第四步：调 K230_LINE_ANGLE_KD

用于圆角地图：

```text
入弯晚 -> 增大
提前甩头 -> 减小
```

### 第五步：调 K230_LINE_TURN_LIMIT

```text
急弯转不过去 -> 增大
转向太猛 -> 减小
```
